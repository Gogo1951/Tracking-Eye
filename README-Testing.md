# Tracking Eye — Manual Test Plan

This is the manual test plan for Tracking Eye — the steps to confirm it works before a release is tagged. For what it does, see [README.md](https://github.com/Gogo1951/Tracking-Eye/blob/main/README.md); for how it works, see [README-Technical.md](https://github.com/Gogo1951/Tracking-Eye/blob/main/README-Technical.md).

## Before you start

**Run the whole list on Classic Era, then `/reload` and run it again on TBC Anniversary.** Steps are numbered continuously so you can report "failed on step N."

Gather these once so you aren't caught short mid-run:

- **Characters.** A character with **Herbalism and Mining** carries most of the plan — Find Herbs and Find Minerals are the two abilities the cycle exists to rotate. A **Hunter** for Track Beasts and Aspect of the Cheetah. A **Druid** for Cat Form and Travel Form. A **Shaman** for Ghost Wolf, if you have one. A **second character on the same account and realm** for the profile steps.
- **Items and bags.** A corpse or container you can loot, and any item you can pick up onto your cursor.
- **Location and state.** Out of combat and out in the open world unless a step says otherwise, on a character with a mount. You also need a town or inn to ride into, a dungeon entrance to zone into, a flight path to take, and something to fight.
- **A non-English client** — only for the optional localization spot-check in step 25.

Running from an unpackaged working copy, the version in the options panel and the mini-map tooltip reads **Dev**. That is correct, not a bug.

This plan deliberately skips the long tail: it does not re-walk every Farm Mode pause reason, every creature type Automatic Target Tracking can resolve, every Diagnostics report button, or the no-tracking-ability character — it covers one representative of each instead.

## Verify this release's changes

This release stops Automatic Target Tracking from firing inside instances, drops the last retired migration line, widens the Feedback & Support link fields, and rewords the note under Use the Default Tracking Button. Run these six first, on both flavors.

**Upgrading from the previous release**

**1.** Log in on a character that already ran the previous release. Its Persistent Tracking Ability, its Farm Mode toggles, and its mini-map button position must all be exactly as you left them. Failure is any of those back at install defaults, which means the upgrade lost that character's settings.

**Automatic Target Tracking stays out of instances**

**2.** On the Hunter, open `/te`, make sure **Enable Persistent Tracking** is ticked, and tick the indented **Automatic Target Tracking** below it. Out in the open world, target a hostile beast. Tracking must switch to **Track Beasts** within a second or so, and the mini-map tooltip must name it as the Persistent Tracking Ability. Failure is nothing happening — the rest of these steps prove nothing if the feature isn't working to begin with.

**3.** Zone into a dungeon and target several hostile mobs of types you can track. Your tracking must **not** change on any of them, and no tracking cast may go off. Failure is tracking switching inside the instance, which spends a global cooldown on every pull.

**4.** Still inside, target a hostile beast, then leave the instance and stand still in the open world for half a minute without targeting anything. Your tracking must **not** switch to Track Beasts. Failure is the switch landing after you zone out, which means the pick was queued from inside the instance and applied minutes late.

**Feedback & Support rows**

**5.** Scroll to the bottom of the main `/te` page. **Discord**, **GitHub**, **CurseForge**, and **Wago** must each show a short label on the left with its URL in a box **beside** it on the same line, and all four boxes must end at the same right edge. Click into one, select all, and copy — the copied address must be the whole link, not a truncated one. Failure is a label stacked above its box, boxes of different widths, or an address cut off at the edge of the field.

**Use the Default Tracking Button**

**6.** On the main `/te` page, read the silver note under **Use the Default Tracking Button**. On an English client it must say Blizzard's tracking **button** opens the **Tracking Menu**. Now tick the option and click Blizzard's own tracking icon on the mini-map: the Tracking Eye menu must open, and only that menu — not Blizzard's, and not both. Untick it and click that icon again: Blizzard's own behavior must be back exactly as it was. Failure is two menus opening, a menu that flickers open and shut, or Blizzard's button staying hijacked after you switch the option off. On a non-English client the note may still read with the older wording until the next localization pass — that is expected, not a failure. If the option is absent entirely, that client has no default tracking button of its own; note it rather than failing the step.

When steps 1–6 pass on both flavors, this release's changes are verified — proceed to `4 - Pre-Launch Review Prompt.md` once the Core checks below pass too.

## Core checks

**7.** Log in with Tracking Eye enabled. No Lua error window may appear and no red error text may print. One line must print in chat reading *"Tracking Eye // Version …"* — it must read as one complete sentence with a version where the number belongs, never `nil` or a stray `%s`. Now type `/reload`: the UI must come back clean and the same line must print again. Failure is any error naming Tracking Eye, or a welcome line with a hole in it.

**8.** Open the settings three ways in turn: type `/te`; Shift + Middle-Click the mini-map button; and press `Esc` → **Options** → **AddOns** → **Tracking Eye**. Each must show the settings **docked inside the Blizzard Options window**, with Tracking Eye selected in the category list on the left, and four entries beneath it in order — **Tracking Eye**, **Farm Mode**, **Profiles**, **Diagnostic Tools**. Failure looks like either nothing happening at all, or a standalone window floating free of the Options frame. **TBC Anniversary is the flavor that historically breaks this**, so a tester who ran only Era has not finished this step.

**9.** Pull a mob and, while still in combat, type `/te`, then Shift + Middle-Click the mini-map button. Both times a line must print reading *"Tracking Eye // As a safety precaution, the Options Interface cannot be opened during combat."* and the panel must stay shut. Kill the mob and stand still — the panel must **not** open by itself once combat ends. Failure is the panel opening, silence with no printed line, a red `ADDON_ACTION_BLOCKED` error naming Tracking Eye, or the panel appearing on its own seconds later.

**10.** Hover the mini-map button and read the tooltip top to bottom. It must show, in order: **Tracking Eye** with the version on the right; a **Farm Mode Status** block while Farm Mode is on; **Tracking Menu** with *Left-Click / Open*; **Persistent Tracking Ability** naming your current ability with its icon, and *Right-Click / Clear Tracking*; **Persistent Tracking** reading Enabled or Disabled with *Shift + Left-Click / Toggle*; **Farm Mode** the same way with *Shift + Right-Click / Toggle*; **Silence Tracking Sounds** with its state; and finally **Tracking Eye Options** with *Shift + Middle-Click*. On a character that can track a creature type, an **Automatic Target Tracking** state row also appears after Persistent Tracking. Failure is a missing block, a state that reads the opposite of the panel, or a raw key like `PERSISTENT_DESC` showing through instead of words.

**11.** Now perform each click the tooltip just named. Left-Click opens the tracking menu beside the button. Right-Click stops tracking, returns the button to the default map icon, and makes the tooltip read **None Set**. Shift + Left-Click flips the **Persistent Tracking** row between Enabled and Disabled, updating in place while you hover. Shift + Right-Click flips the **Farm Mode** row the same way. Each must match the matching checkbox in `/te`. Failure is any click doing nothing, doing something else, or the panel and tooltip disagreeing.

**12.** Left-Click the button to open the tracking menu. It must list one row per tracking ability **you actually know**, each with its spell icon and name, sorted alphabetically under a **Tracking Menu** title. Click one: the menu closes, the ability is cast, the button's icon changes to it, and reopening the menu shows a check mark on that row. Failure is abilities you don't know appearing, one you do know missing, a row with no icon, or nothing being cast. **Find Fish is Anniversary-only** — on Classic Era it must never appear for any character, because that spell does not exist on that client.

**13.** On a Druid **not** in Cat Form, open the tracking menu. **Track Humanoids** must not be listed. Shift into Cat Form and open it again — it must now appear and be castable. Failure is the row showing out of form, where it could not be cast anyway.

**14.** With **Enable Persistent Tracking** ticked, pick Find Herbs, then die and run back to your corpse. Within a couple of seconds of resurrecting, Find Herbs must be recast — the herb dots must be back before you've moved. Die again and take an in-place resurrection instead (a healer's rez, a soulstone, or the spirit healer): tracking must come back the same way. Failure is tracking staying down after either kind of resurrection.

**15.** On the Druid with tracking up, shift into Cat or Bear Form and back out. Tracking must be recast a second or two after you leave form. Then untick **Enable Persistent Tracking**, die, and resurrect — tracking must **not** come back on its own. Failure is tracking staying down after a shapeshift, or a recast happening with the feature switched off.

**16.** With Find Herbs and Find Minerals both ticked on the **Farm Mode** page, mount up in the open world. The mini-map tracking icon must change every few seconds, alternating between the two, with herb dots and ore dots alternating on the mini-map. Dismount: the cycle must stop and your Persistent Tracking Ability must be restored within a tick or two. Now untick all but one ability and mount again — that single ability must be kept up, and cancelling it by hand must get it recast within a tick or two. Failure is tracking sitting on one ability while several are ticked, the cycle continuing on foot, or a one-ability cycle doing nothing at all.

**17.** Check the Farm Mode conditions by class. **Travel & Flight Forms** must be offered only to a Druid, **Aspect of the Cheetah** only to a Hunter, and **Ghost Wolf** only to a Shaman, while **Mounted** and **Not Mounted** appear for everyone. Tick the condition your class has and enter that state — the cycle must run. Untick it while staying in that state and the cycle must stop. Failure is a condition offered to a class that can never reach it, or a ticked condition that doesn't start the cycle.

**18.** Mounted with the cycle running, ride into a town or inn: the tooltip must read **Paused** in grey with *"In a town or inn."* underneath, and the tracking icon must visibly **dim**. Repeat by zoning into a dungeon (*"Inside an instance."*) and by taking a flight path (*"On a flight path."*) — both must pause and dim. Now tick **Not Mounted**, stand on foot in the open world, and pull a mob: the tooltip must read **Paused** with *"In combat."*, but the icon must **not** dim. Failure is the cycle firing casts in a city, an instance, or on a gryphon, a status that never changes, or an icon that dims and undims through every fight.

**19.** With the cycle running, do each of these one at a time: open a merchant or your bank, hover an item in your bags long enough to read its tooltip, open a loot window on a corpse, and pick an item up onto your cursor. In each case the cycle must stop while that is true and resume within a tick of you closing or clearing it. Then hover the Tracking Eye icon itself — the cycle must **keep running**, because reading our own tooltip is not a pause. Failure is a tracking cast going off underneath an open window, closing your loot window, or dropping what was on your cursor.

**20.** On the **Farm Mode** page, confirm **Silence Tracking Sounds** is **ticked** on a fresh profile. With your sound on, mount up and let the cycle run for half a minute: the repeated tracking-cast sound must not play. Open the tracking menu and pick an ability by hand — that cast **must** be audible. Now `/reload` mid-cycle and check the game's Sound options: **Sound Effects must still be enabled**. Untick the option mid-cycle and sound must return immediately. Failure is hearing the cycle, losing the sound on your own manual cast, or sound effects left switched off after the reload.

**21.** Open the game menu, choose **Key Bindings**, and find the **Tracking Eye** section. One binding must be listed, named **Cycle Farm Mode Ability**. Bind it to a spare key. With two or more abilities ticked, press it out of combat with **Farm Mode switched off** — tracking must still advance one ability per press, because this is a manual control. Press it while in combat and again with a loot window open: nothing may happen. Then untick every ability **and** the **Persistent Tracking Ability** toggle above the list and press it again — a line must print reading *"Tracking Eye // No tracking abilities are selected for Farm Mode. Pick some under Options > AddOns > Tracking Eye."* Failure is no Tracking Eye section at all, the key doing nothing with a full list, a cast going off mid-fight, or silence with an empty list.

**22.** On the main page, tick **Enable Free Placement Mode**. The mini-map button must disappear, a standalone tracking icon must appear, and **Enable Mini-map Button** must grey out. Drag the icon to a corner, `/reload`, and it must come back in the same place; change your interface scale and it must hold that place rather than drifting. Switch **Icon Shape** between Circle and Square and drag **Icon Size** end to end — both must change the icon live without moving it. Hover and click it: the tooltip and every click must behave exactly as they do on the mini-map button. Untick the option and the mini-map button must return, respecting whatever **Enable Mini-map Button** was set to beforehand. Failure is both icons showing at once, an icon that jumps to screen centre after a reload or a scale change, or the mini-map button coming back when you had it switched off.

**23.** Open `/te` → **Profiles**. It must show your current profile named for this character in the shape *Name - Realm*, not a shared **Default**. Set a distinctive Persistent Tracking Ability and cycle interval here, then log in on the second character on the same account: that character must have its **own** tracking settings, while the welcome-message toggle, the mini-map button's position and visibility, and everything under Free Placement Mode match the first character. Failure is the second character inheriting the first's ability or interval, or its own mini-map layout.

**24.** Back on the first character, change several Farm Mode settings and click **Reset Profile**. The tracking and Farm Mode settings must return to install defaults and the pages must show the reset values as soon as you click back to them, **without** a `/reload`. Confirm what it did **not** touch: the welcome-message toggle, the mini-map button's position and visibility, and Free Placement Mode must be exactly as they were. Failure is settings surviving the reset, pages showing stale values until you reload, or the reset wiping account-wide layout along with the character's own settings.

**25.** Open `/te` → **Diagnostic Tools** on a fresh login. Only the warning paragraph and the **Enable Diagnostic Tools** toggle may be visible, and that toggle must be **off**. Tick it: eleven sections must appear without reopening the panel — Event Log, Event Registration, API Endpoints, Player & Spell Context, Display Context, Farm Mode Context, Other Add-ons, Saved Variables, Library Versions, Taint Log, and External Tools. Click **Test Event Registration** (every row must read `[PASS]`; an `IsEventValid: n/a` is not a failure), **Test WoW API Endpoints** (rows reading `[n/a]` are the legacy half of a compatibility pair and are expected — only `[FAIL]` counts), and **Check Farm Mode State** while mounted (its toggles, movement state, and ability list must match what the Farm Mode page shows; the pause reason prints as a short code rather than a sentence, which is deliberate). Untick the toggle and everything below must vanish; `/reload` and it must still be off, because diagnostics is session-only by design. Failure is the toggle on by default, any `[FAIL]` row, a report that contradicts the panel, or diagnostics surviving a reload.

**26.** *Optional, non-English client only.* Read the main page, the Farm Mode page, and the mini-map tooltip in that language, then ride into a town and hover the button. Every label, description, note, and pause reason must render as words in that language, and the welcome line and the cycle dropdown must each carry their number in a sensible place. Failure is a raw key showing through — text like `OPTIONS_FARM_NOTE` or `FARM_PAUSED_RESTING` on screen instead of a sentence — or `nil`, a stray `%s`, or a doubled value where a number belongs. Run this on **ruRU** where you can: Cyrillic is the widest-encoding locale the add-on ships, so a string that overruns its layout shows there first.

When every step passes on both Classic Era and TBC Anniversary, manual testing is complete — proceed to `4 - Pre-Launch Review Prompt.md`.
